## como guardar un proyecto en gitHub
- 1. en el menu desplegable de la derecha signo + > new repository
- 2. aqui si coloco el nombre del proyecto la descripción , el resto si se deja igual > create repository
- 3. ya teniendo en mi local la carpeta creada y la consola abierta copio y pego todo el comando que me da gitHub
     sigo las indicaciones de la consola y listo proyecto cargado
